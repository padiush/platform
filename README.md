# Padiush
## Acerca del proyecto

Con el fin de agilizar la recolección, procesamiento y exportación de datos en investigaciones etnobotánicas, se desarrolló un sistema informático accesible desde la web, que puede llegar a utilizarse como un compendio colaborativo de conocimiento etnobotánico a nivel regional.

## Tecnologías

El proyecto está desarrollado en [Laravel](https://laravel.com) 9.x para el backend, y [TailwindCSS](https://tailwindcss.com) con la extensión [DaisyUI](https://daisyui.com) para el frontend.
