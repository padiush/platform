# Padiush

## About the Project
Padiush is a web-based bioinformatics tool designed to simplify the collection, processing, and export of data in ethnobotanical research. The system aims to streamline workflows, making data handling more efficient for researchers in this field.

## Features
- **Form Designer**: A feature that allows users to create and customize data collection forms.
- **Cross-Platform Accessibility**: Accessible through any modern web browser.

## Getting Started
To set up the project locally, follow these steps:

### Prerequisites
- PHP 8.2 or higher
- Node.js and npm
- Composer

### Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/raarevalo96/padiush.git
    ```
2. Navigate to the project directory:
    ```bash
    cd padiush
    ```
3. Install dependencies:
    ```bash
    composer install
    npm install
    ```
4. Run database migrations:
    ```bash
    php artisan migrate
    ```
5. Start the development server:
    ```bash
    php artisan serve
    ```

## Running with Docker

A Docker Compose environment is provided with PHP 8.4, Node 22, MariaDB 11.8, MinIO (stands in for S3), and Mailpit (catches outgoing mail). It reuses your existing `.env`; database, S3, and mail settings are overridden by container environment variables, so the non-Docker setup keeps working unchanged.

1. Start the stack (first run builds the PHP image and installs dependencies):
    ```bash
    docker compose up -d
    ```
2. If your `.env` has an empty `APP_KEY`, generate one:
    ```bash
    docker compose exec app php artisan key:generate
    ```
3. Run the migrations and seed the capability roles:
    ```bash
    docker compose exec app php artisan migrate --seed
    ```
4. Open the services:
    - App: http://localhost:8000 (Vite dev server with HMR runs on port 5173)
    - Mailpit UI: http://localhost:8025
    - MinIO console: http://localhost:9001 (login `padiush` / `padiush-secret`)
    - MariaDB: localhost:3307 (user/password/database: `padiush`, root password: `root`)

Notes:

- The `minio-setup` one-shot container creates the `padiush` bucket and uploads placeholder images for the public/auth pages (generated by `docker/minio/generate-seed-images.php`). Replace them via the MinIO console if you want real ones.
- The app runs `artisan serve --no-reload`, so `.env` edits require `docker compose restart app`.

Useful commands:
```bash
docker compose exec app php artisan tinker   # or any artisan command
docker compose exec app composer require ...
docker compose exec node npm install ...     # node_modules lives in a container volume
docker compose logs -f app node              # tail app and Vite logs
docker compose down                          # stop; add -v to also drop the database
```
